# User Flow: 지능형 테스트 및 운영 시나리오

1. **소스트 선택:** 상단 탭에서 [Webcam], [Image], [Video] 중 선택.
2. **미디어 로드 및 자동 매칭:**
   - 파일을 업로드하면 시스템이 `SourceID`를 분석.
   - 해당 파일에 대해 **과거에 설정했던 주차 구역 좌표가 있다면 자동으로 로드**.
3. **구역 설정 및 수정 (필요 시):**
   - 캔버스 위를 클릭하여 다각형 생성.
   - 수정 시 해당 소스(`SourceID`)의 데이터만 독립적으로 업데이트.
4. **실시간 모니터링:** - [분석 시작] 시 AI가 구역별 점유 상태를 판단하여 시각화.
   - 소스를 바꿔도 각 소스에 맞는 좌표 레이어가 즉시 교체됨.
