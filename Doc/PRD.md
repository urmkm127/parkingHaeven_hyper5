# PRD: 멀티 소스 및 소스별 좌표 관리가 가능한 AI 주차 탐지 웹앱

## 1. 프로젝트 개요
사용자가 웹캠, 이미지, 비디오 등 다양한 입력 소스를 통해 주차 공간을 모니터링하고, 각 소스에 최적화된 주차 구역 설정을 독립적으로 관리할 수 있는 브라우저 기반 AI 솔루션.

## 2. 핵심 기능 (Core Features)
- **멀티 입력 소스 지원:** - Real-time Webcam
  - Static Images (JPG, PNG)
  - Recorded Videos (MP4)
- **소스별 독립적 ROI(주차구역) 관리:** - 각 파일명(또는 웹캠 ID)을 키값으로 하여 주차 구역 좌표를 개별 저장/로드.
- **온디바이스 AI 추론:** ONNX Runtime Web을 사용한 YOLOv8-nano 모델 실행.
- **실시간 대시보드:** 점유(적색)/미점유(녹색) 시각화 및 잔여 주차면수 표시.
- **스마트 알림:** 상태 변경 시 Notification API 및 오디오 알림.

## 3. 기술적 제약
- 서버 없는 정적 웹사이트(GitHub Pages) 배포 구조.
- LocalStorage를 활용한 영구적 데이터 관리.
