Doc 폴더에 제공된 md 문서들을 완벽히 분석해줘. 이 프로젝트는 GitHub Pages에 배포할 'Serverless AI 주차 관리 시스템'이야. Parking-Detector폴더의 웹 UI 방식과 YOLOv8 ONNX 추론을 결합한 형태로 개발을 시작하고 싶어.
프로그램 개발은 Source 폴더 안에서 진행해줘.

이 프로젝트는 웹캠뿐만 아니라 사용자가 업로드한 이미지나 영상 파일로도 주차 탐지를 수행할 수 있어야 해.

작업 우선순위:

index.html에 웹캠/이미지/비디오 입력을 선택할 수 있는 탭 UI와 파일 업로드 버튼을 만들어줘.

입력받은 소스(이미지든 영상이든)를 하나의 메인 Canvas에 일관되게 출력하는 렌더링 파이프라인을 구축해줘.

**가장 먼저 구현해야 할 핵심 사항:**
1. 웹캠, 이미지, 영상을 모두 수용할 수 있는 통합 `MediaHandler`와 메인 `Canvas`를 만들어줘.
2. 사용자가 파일을 바꿀 때마다 **파일명에 매칭되는 독립적인 주차 구역 좌표**를 LocalStorage에서 불러오고 저장하는 `StorageManager`를 구현해줘.
3. UI는 Tailwind CSS를 사용해 현대적이고 깔끔한 대시보드 형태로 구성해줘. 설정 모드와 감시 모드를 쉽게 오갈 수 있어야 해."
