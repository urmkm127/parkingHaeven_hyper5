# 샘플 파일 폴더

이 폴더에 테스트용 이미지와 비디오를 넣으세요.

## 폴더 구조

```
samples/
├── images/    # 주차장 이미지 샘플 (jpg, png, etc.)
└── videos/    # 주차장 비디오 샘플 (mp4, webm, etc.)
```

## 사용 방법

1. `samples/images/` 폴더에 주차장 이미지를 넣으세요
2. `samples/videos/` 폴더에 주차장 비디오를 넣으세요
3. 웹페이지에서 이미지/비디오 탭을 선택하면 샘플 파일 목록이 표시됩니다
4. 샘플 파일을 클릭하면 바로 로드됩니다

## 샘플 파일 추천

- 주차장이 잘 보이는 사진
- 차량이 주차된 영상
- 다양한 각도와 조명의 이미지
