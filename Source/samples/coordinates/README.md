# 주차 구역 좌표 파일

이 폴더에는 미리 설정된 주차 구역 좌표 JSON 파일을 저장합니다.

## 파일 명명 규칙

파일명이 소스 파일과 동기화됩니다:

| 소스 파일 | 좌표 파일 |
|----------|----------|
| `1.mp4` | `1.mp4_regions.json` |
| `2.jpg` | `2.jpg_regions.json` |
| `sample.png` | `sample.png_regions.json` |
| 웹캠 | `webcam_regions.json` |

## 파일 형식

```json
{
  "SOURCE_ID": [
    {
      "id": 1,
      "points": [
        {"x": 100, "y": 200},
        {"x": 150, "y": 200},
        {"x": 150, "y": 250},
        {"x": 100, "y": 250}
      ],
      "occupied": false
    }
  ]
}
```

## 사용 방법

### 좌표 내보내기

1. 해당 파일(예: 1.mp4)을 열고 주차 구역 설정
2. **📤 현재 파일 좌표 내보내기** 버튼 클릭
3. `1.mp4_regions.json` 파일이 다운로드됨
4. 이 폴더에 저장

### 좌표 가져오기

1. **📥 좌표 가져오기** 버튼 클릭
2. 이 폴더의 JSON 파일 선택
3. 해당 소스를 열면 자동으로 좌표가 적용됨
